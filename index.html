Hubungkan database

Tambahkan kredensial project Supabase lokal agar bisa membuat akun dan mulai mencatat.

  1. Salin .env.example menjadi .env.local.
  2. Isi URL project dan anon/publishable key dari pengaturan API Supabase, lalu mulai ulang Vite.
  3. Jalankan supabase/schema.sql di Supabase SQL Editor, lalu muat ulang aplikasi.

Jangan masukkan service_role key ke aplikasi.
